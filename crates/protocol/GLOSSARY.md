# Protocol glossary

| Term | Meaning |
| --- | --- |
| Event | Input that reaches the core, such as `button` (name, pressed or released). |
| Action | What the core asks its edges to do, such as `key` (an Enter tap to the focused client). |
| Button name | A controller button named by position: South, East, North, West for the face buttons. South is A on an Xbox pad. |
