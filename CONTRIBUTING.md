# Contributing

Run `scripts/check` before every commit; CI runs the same gate. Review rules are in [CODING_STANDARDS.md](CODING_STANDARDS.md).

Contributors donate their copyright to the owner. The pull request template says so. The owner promises that licensing choices will benefit the project, judged by the test in [ADR 0004](docs/adr/0004-licensing.md). Those who do not want to donate can write a plugin instead.

Some countries do not allow copyright to be given away. Germany is one. There the fallback is an exclusive, perpetual, irrevocable licence that includes the right to relicense.
